# CHE LAP Generator

Practice games (Roll and Read, Bingo, Tic Tac Toe, Ups and Downs, Word Quiz Board)
and stories for SIPPS Beginning, Extension, and Challenge groups.

Created to align with the SIPPS® scope and sequence. Not made by or affiliated with
the Center for the Collaborative Classroom.

## Run it in Codespaces

```bash
npm install
npm run dev
```

## Built with

- Vite + React (JavaScript), ESLint, React Router
- Firebase (sign-in, Firestore, Cloud Functions, Hosting): coming in later stages
